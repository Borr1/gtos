## Self-Red-Team Notes

The strongest remaining risk is evidence provenance confusion. The current Mac integration branch has zero missing current-branch LFS objects, but any claim that depends specifically on VPS runtime/source-machine provenance must use a role-labeled `vps_runtime_path` cache and manifest rather than silently treating a Mac package or LFS payload as VPS runtime truth.

The second risk is stale broad doctrine language. The prompts counteract that locally by stating the current full repo-control rule and marking stale restrictive implementation language as superseded for final moonshot repo changes.

The third risk is write-scope collision if three code-changing goal sessions share one Git worktree at the same time. The active launch mode removes that race by running Wave 1A, Wave 1B, and Wave 1C in separate linked worktrees with scoped route branches, then merging through the integration owner.

The fourth risk is stale route-local starter text. The old Wave 1A route-local starter was replaced; Wave 1B and Wave 1C route-local starters were added.
