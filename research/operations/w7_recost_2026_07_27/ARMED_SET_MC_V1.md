## 1. The sizing gap

`published` is the convention every figure the owner has seen was computed at: `risk = dial x (sd_reference / sd_variant)` (`build_survivor_book.py:64`). `live` is what the deployable path does: `base_risk = ALLOCATION_PROFILES[profile].risk_per_unit_A` (`admission.py:1424`), then `x gov.size_cap_multiplier` (`:1473`, <= 1.0) and `unit_risk = base x conf x derisk_mult` (`:1212`) — **no volatility term in the configured profile.** Stated that way on purpose: the module does carry a vol term, `CLEAN3_VOL_SCALE = 0.9481` pre-multiplied into every W5 `clean3_*` profile (`:686-731`); the W7 dials dropped it deliberately (`:752-760`). Plus the half-Kelly bins that `ultimate_book_kelly_conservative: true` selects.
