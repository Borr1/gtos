## Pre-registration (committed before looking at fill numbers)

### FVG detection (copied verbatim from `src/components/market_state.py::identify_fvgs`)

```
for i in range(1, len(candles) - 1):
    bull_gap = candles[i+1].low - candles[i-1].high
    if bull_gap >= min_gap_size:
        top = candles[i+1].low; bottom = candles[i-1].high
    bear_gap = candles[i-1].low - candles[i+1].high
    if bear_gap >= min_gap_size:
        top = candles[i-1].low; bottom = candles[i+1].high
```

### Fill definitions
- **Bullish partial:** any bar k >= i+2 with `low[k] <= top` (price enters the gap)
- **Bullish full:** any bar k >= i+2 with `low[k] <= bottom` (price fills the gap completely). This matches the production `filled` flag.
- **Bearish partial:** any bar k >= i+2 with `high[k] >= bottom`
- **Bearish full:** any bar k >= i+2 with `high[k] >= top`. Production `filled` flag.

### Horizons (M15 bars after impulse close at i+1)

- [5, 10, 20, 50, 100] bars  (~1.25h / 2.5h / 5h / 12.5h / 25h)

### Hypotheses
- **H0:** fill rates homogeneous across symbols at the 20-bar horizon (full-fill).
- **H1:** at least one symbol deviates by >= 10pp vs pooled.
- **Tests:** 2x5 chi-square overall; pairwise 2x2 chi-square with Bonferroni alpha/10 = 0.005.
- **Sample threshold:** n >= 50 events per symbol for full inclusion; n < 30 => excluded from Bonferroni set.

## Interpretation

### Cross-symbol effect is statistically detectable but economically minor

All five symbols fill between 66.6% (XAUUSD) and 71.5% (GBPJPY) of FVGs completely within 20 M15
bars (5 hours). The overall chi-square is highly significant purely because sample sizes are
enormous (n = 51,593). The **largest absolute deviation from the pooled rate is 3.4pp (XAUUSD)**,
well below the pre-registered ≥10pp bar. The null (H0) cannot be rejected at the economic
threshold that would justify a symbol-specific filter: the pre-registered H1 is **not supported**.

Pairwise pattern: XAUUSD is consistently the slowest-filling (vs every other symbol), and US30
is second-slowest. The two JPY pairs (USDJPY, GBPJPY) fill fastest. This is consistent with
gold/index having more one-directional structural momentum (FVGs act as displacement markers
that aren't revisited), while JPY pairs mean-revert more frequently — but again, the magnitude
does not warrant a filter.

### FVG size (in ATR14 units) is a massive quality signal

At H=20, full-fill rate drops monotonically from **76.0%** (gap < 0.5×ATR) to **36.4%** (gap ≥ 2×ATR):

| Bucket | n | full_fill@20 |
|--------|---|--------------|
| [0, 0.5×ATR) | 29,655 | 0.760 |
| [0.5, 1.0×ATR) | 15,363 | 0.664 |
| [1.0, 2.0×ATR) | 5,408 | 0.549 |
| [2.0×ATR, ∞) | 1,158 | 0.364 |

Chi-square across buckets: chi2=1,814, df=3, p≈0. The effect is monotone and consistent within
every symbol (see per-symbol stratification table). **This is a much stronger signal than the
existing "FVG-in-impulse" detection.**

### Practical implication

The existing FVG-in-impulse signal (+7–20pp across 6 instruments, validated) detects the
presence of an FVG inside an impulse leg. This study suggests an additional
**"big-gap ≠ strong signal"** insight: large FVGs (≥ 2×ATR) behave very differently — they
fail to fill nearly 2/3 of the time within 5h and remain open longer. Either this represents
genuine structural displacement (continuation) or it reflects that tails of the gap-size
distribution are rarer events with different dynamics (news, regime shifts).

Since the existing FVG signal is already binary (present/absent) and is not directly a
trade-gate, the question for CEO/strategy is whether to:
1. **Enrich the FVG-in-impulse detector** with `gap/ATR` magnitude as a feature (R2 candidate
   logger), so the T7 prompt can see "FVG: 2.1×ATR" rather than "FVG: yes".
2. **Add a fill-probability annotation** for the MSO (e.g., "FVG at 2.1×ATR → 36% base-rate
   fill within 5h"), allowing the model to discount FVGs as retest targets when large.
3. **Do nothing** — this is observational research; FVG is not an entry trigger in the current
   pipeline (OB retest is), and the fill rate is not on the critical path.

Recommendation: observational (#1) via the existing R2 candidate features logger. No config
or prompt change. Re-evaluate if T7 later gates on FVG as an additional "quality" signal.

### Caveats

- **Survivorship across horizons:** Censoring at each horizon is handled (rates computed only
  on uncensored events). At H=100, fewer than 0.2% of events are censored per symbol, so this
  is immaterial.
- **`none` bucket:** First 14 bars of each file have no ATR14 and contribute 9 events
  pooled — irrelevant.
- **Broker-specific `fvg_min_gap`:** GBPUSD and USDJPY have price-based thresholds (0.000145
  and 0.015 respectively); XAUUSD uses the default 1.0. The chi-square is performed on
  *detected FVGs per symbol's own threshold*, not on a standardized cross-symbol grid. If
  thresholds were unified in ATR terms, per-symbol counts would re-balance, but since the
  production pipeline uses exactly these thresholds, this is the correct comparison for
  "what does the system see?".
- **M15 only:** This study is M15. H1 and H4 FVG fill dynamics may differ (time horizon
  scales). Out of scope for Q-2.4.
