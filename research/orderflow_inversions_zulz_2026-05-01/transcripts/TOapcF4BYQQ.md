> If you're using Trading View to trade orderflow, to trade volume profiles, footprint charts, it's okay if you're just starting out, if you're learning, but if you want to take your trading to the next level, you have to find other tools instead of Trading View. You are pretty much using fake data. You're using aggregated volumes and orders that do not show you the real exact picture of what's happening in the market. If you want to have the most precise information in order for you to trade orderflow, you need to be using tools like Quantower, like Sierra Chart, like Atas. These are the only tools that will show you real time precise orderflow data.
