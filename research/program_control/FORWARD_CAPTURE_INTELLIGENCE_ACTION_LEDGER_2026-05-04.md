## Purpose

This ledger maps the forward-capture and intelligence infrastructure goal into concrete work items. It is intentionally exhaustive rather than priority-only: every item from the expanded-OOS deep dive sections 16 through 29, the final synthesis remaining triggers, and the goal prompt tracks A through U must resolve to a concrete terminal status.

Allowed terminal statuses:

- `DONE`
- `IMPLEMENTED_SHADOW_ONLY`
- `RESEARCH_ARTIFACT_DONE`
- `WAITING_FOR_FORWARD_ROWS_WITH_COLLECTOR_ACTIVE`
- `BLOCKED_WITH_EVIDENCE_AND_TRIGGER`

No row may remain as vague pending in the final synthesis.

## Canonical Evidence Labels

| Evidence label | Meaning |
|---|---|
| `BROKER_ACTUAL_R` | MT5/account/deal backed realized outcome only. |
| `INTERNAL_LIMIT_LIFECYCLE` | Local pending-intent trigger/fill/cancel/expiry telemetry. |
| `SYNTHETIC_PATH_R` | OHLC/path-replay result, not broker-realized truth. |
| `FUTURES_PROXY_TRANSFER` | Futures source mapped to CFD decision context; not broker truth. |
| `SAME_MARKET_SOURCE_TRANSFER` | Same-market non-broker source, e.g. Sierra XAUUSD, mapped to GTOS context. |
| `CROSS_INSTRUMENT_CONTEXT` | Context/control source such as CL, ZN, or VIX/VXM. |
| `FORWARD_SHADOW` | Forward-only, no-decision-impact logging/collection. |
| `DISCOVERY_ONLY` | Exploratory research output that cannot validate or promote. |
| `CONTROL_ONLY` | Context/control data that cannot validate direct strategy performance. |

## Common Forward Log Metadata Fields

All new forward logs and ledgers created in this goal should use these fields when the source can provide them:

`schema_version`, `created_at_utc`, `symbol`, `broker_symbol`, `source_symbol`, `session`, `kill_zone`, `side`, `regime`, `candidate_id`, `trade_id`, `evidence_class`, `decision_time_utc`, `asof_cutoff_utc`, `source_file`, `source_hash`, `no_leak_status`, `promotion_verdict`.

When a field is unavailable, the row should preserve the key with `null` or write a companion blocker/status reason rather than silently omitting the lane.
