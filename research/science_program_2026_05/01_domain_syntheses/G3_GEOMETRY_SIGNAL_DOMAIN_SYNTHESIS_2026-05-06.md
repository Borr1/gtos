## Domain Synthesis

The highest-confidence primitive for GTOS translation is not a public "fractal trading strategy." It is time deformation: market information arrives irregularly, and wall-clock bars mix quiet periods with high-information displacement periods. Directional-change event clocks and wavelet/HAR scale decompositions both attack that problem from different sides. DC converts price movement into intrinsic events; wavelets/HAR split wall-clock paths into scale-local energy components.

GTOS already has a strong structure feature base, so G3 should not duplicate raw swing counts or MTF alignment. The research value is in testing whether intrinsic-time and scale-decomposed features add information after controlling for existing structure, regime, and volatility families.

Hurst, GHE, DFA, and MFDFA are useful only with caveats. In financial data, apparent long memory can be heavy-tail bias, short-memory contamination, or regime switching. Therefore these rows are framed as context/regime hypotheses, not direct entry rules. The key GTOS question is whether memory/roughness shifts precede already-documented OB/structure decay.

TDA and path signatures are the most speculative but still measurable. They can encode path geometry without hand-coded ICT labels, but their feature spaces can explode relative to GTOS sample size. They remain blocked behind strict sample floors, dimensionality reduction, and nested validation.

## Counter-Evidence And Decay-Mode Review

- Directional-change scaling laws can be stable in FX while still failing for GTOS symbols, sessions, and broker spreads. DC features may collapse when volatility regime or quote granularity changes.
- Overshoot features can accidentally become a sweep-reversal proxy. GTOS has prior evidence that simple sweep framing can mislead; DC rows require continuation/exhaustion controls and must not assert stop-hunt behavior.
- Wavelet decompositions are sensitive to basis, boundary handling, padding, and lookback length. MODWT alignment must be point-in-time; circular boundary wrap is blocked for trading features.
- HAR/wavelet volatility components may be redundant with existing ATR/RV/range-expansion features. Every experiment must include current volatility-family baselines.
- Hurst and DFA estimates are biased by heavy tails, finite samples, short-range dependence, and regime switching. Raw Hurst-on-returns is blocked; GHE/DFA/absolute-return variants require estimator sensitivity checks.
- Multifractal spectrum width can be an artifact of non-stationarity or finite sample length. Surrogate tests and shuffled controls are mandatory before any result can be interpreted.
- TDA features can overfit because persistence diagrams generate many summaries. Use low-dimensional persistence summaries first and nested validation.
- Path signatures can become high-dimensional and label-leaky if the path includes post-decision bars. Only windows ending at decision time are allowed.
- Existing swing-protected structural lift has concentration risk. All G3 geometry rows must control for symbol/session/side concentration and duplicate active setup lifecycle.
