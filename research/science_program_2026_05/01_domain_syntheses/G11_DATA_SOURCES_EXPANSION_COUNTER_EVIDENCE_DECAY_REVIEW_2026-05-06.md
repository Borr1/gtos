|---|---|---|
| Source coverage decay | Recent-only or symbol-skewed data can rank instruments that only look good in one period | Coverage manifest by symbol/source/date before any performance claim |

| Release-lag contamination | Macro/positioning rows joined by observation date can see data before publication | Publication/as-of timestamp joins and vintage tests |

| Friction decay | Spread, min-lot, weekend gaps, and session density can destroy mechanical edge out of sample | Friction gate before candidate ranking |
| Definition drift | Footprint/profile/imbalance definitions can be tuned after seeing outcomes | Definition freeze before feature extraction |
| Observer leakage | Observer candidates can be promoted after attractive anecdotal logs | Outcome-review-open flag must remain false until prereg/sample floor |
