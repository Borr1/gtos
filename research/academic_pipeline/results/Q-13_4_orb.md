# Q-13.4 Opening Range Breakout (ORB) on XAUUSD H1

Generated by `research/academic_pipeline/scripts/q_13_4_orb.py` (local, $0 API).

## Hypotheses (pre-registered, BEFORE looking at data)

**Primary — Q-13.4**: Opening-range-breakout on XAUUSD (M15, first 4 candles
of each kill zone as the opening range) does NOT add independent edge beyond
kill-zone-time filtering. Null expectation is 6-candle continuation WR
approximately 50% both inside and outside kill zones.

**Prior belief**: GTOS's validated edge is OB zone precision (stop-cascade
mean-reversion). ORB is a momentum-ignition / continuation mechanism — the
OPPOSITE directional bet from fading a retest. Osler (2000-2005) and Cont
et al. (2014) support fade-the-cascade, not ride-the-cascade, for round-clock
XAUUSD on this horizon. I therefore expect:

1. 6-candle continuation WR <= 55% in both kill zones (Bonferroni-adjusted
   p >= 0.025). If any cell beats the 55% bar with Wilson-lower-CI > 55% and
   Bonferroni-corrected p < 0.025, that would be a surprise candidate worth
   promoting.
2. Reversal-back-into-OR rate within 12 M15 candles >= 55% (the mean-reversion
   prior: breakouts are more likely false than follow-through on a 3-hour
   horizon).
3. Average R at kill-zone close <= 0 or dominated by variance (|mean/SE| < 1.5).
4. Per-day ORB-long-then-hold-to-kz-close expectancy <= 0 on average
   (paired comparison against no-trade baseline which has 0R).
5. ORB events INSIDE kill zones do not materially outperform events OUTSIDE
   kill zones (WR delta within the 95% CI band of the smaller sample).

**Pre-registered threshold for PROMOTE**: n >= 20 ORB events per KZ AND
continuation WR >= 55% at 6-candle horizon AND Bonferroni-corrected p < 0.025
(for 2 primary comparisons: London KZ and NY KZ).

**Pre-registered threshold for KILL**: WR < 55% with upper 95% CI bound
below 60% in at least one KZ at n >= 20, OR reversal rate > 55% within 12
candles, OR average R at kill-zone close is not positive with |t| > 1.96.

**Pre-registered threshold for DEFER**: Between KILL and PROMOTE — WR in
[50%, 55%] band, or n < 20 per KZ (underpowered).

**Flag condition**: If OR range correlates > 0.8 with contemporaneous ATR(14)
on H1, the ORB signal is not independent from volatility; it would need to
be compared against an ATR-matched null to make a fair claim.

## Data

- Source: `data/historical_2026/XAUUSD_M15.csv` (2026-01-02 .. 2026-04-10, 6420 M15 bars).
- Timestamps taken as-is from the CSV (broker time); kill-zone hours applied
  directly using the same convention as `q_14_non_zone.py` (London 07:00-10:30, NY 13:00-17:00).
- Opening range definition: first 4 M15 candles (60 min) inside each kill zone
  on each trading day. London OR uses 07:00, 07:15, 07:30, 07:45. NY OR uses
  13:00, 13:15, 13:30, 13:45.
- An "ORB signal" is the first subsequent M15 candle that CLOSES strictly
  outside the opening range [OR_low, OR_high] within that same kill zone.
  Long if close > OR_high. Short if close < OR_low.
- In-KZ ORB events: breakout must occur BEFORE kill-zone end (London 10:30,
  NY 17:00). Out-of-KZ ORB events: on days where no in-KZ breakout occurred,
  we track the first close-outside-OR in the 12 M15 candles AFTER kill-zone
  end (i.e., London after 10:30, NY after 17:00).
- Only trading days with all 4 OR candles present and at least 1 candle
  beyond the OR window in the same KZ were considered.

## Method

For each (day, kill_zone) pair with a complete OR window:

1. Compute `OR_high`, `OR_low`, `OR_range = OR_high - OR_low`.
2. Walk forward M15 candles inside the kill zone. First candle whose `close`
   closes strictly outside [OR_low, OR_high] = the ORB signal.
3. Classify direction: LONG if close > OR_high; SHORT if close < OR_low.
4. Compute outcomes (anchored at signal candle close):
   - **Continuation** at 6-candle horizon: direction of 6-bar-forward close
     relative to signal close (long: win if forward_close > signal_close).
   - **Reversal**: at any of the next 12 candles, does price RETURN
     inside the OR band (low <= OR_high AND high >= OR_low for long
     signals — i.e., price touches back into the range)?
   - **1R target outcome** (R = OR_range): did price reach `signal_close + R`
     (long) or `signal_close - R` (short) before reaching `signal_close - R`
     (long SL = 1R adverse from signal close), walking forward candle by candle?
     Pure first-touch; no mid-bar path reconstruction.
   - **Kill-zone-close R**: (kz_close_price - signal_close) / R for long,
     inverted for short.
5. Run the same pipeline for "out-of-KZ" ORB breakouts that occur up to 12
   M15 candles AFTER kill-zone end, using the same in-KZ OR as the range.
6. ATR(14) context: compute ATR on H1 (rolling 14-hour true range). Record
   `OR_range / ATR(14)` per event. Report Pearson correlation to flag
   volatility confounds.

Statistics:

- Wilson 95% CI for binomial proportions (continuation WR, reversal rate).
- Two-sided exact binomial test against p0 = 0.50 (null: coin flip) for
  continuation WR. Bonferroni correction factor = 2 (London, NY) for the
  primary pre-registered threshold.
- One-sample t-test on kill-zone-close R across events.

## Caveats

1. **Sample is short (3.3 months of M15 data, 2026-01-02 .. 2026-04-10).**
   At best ~70 trading days per kill zone; some days will lack a breakout
   inside the kill zone, further reducing per-bucket n.
2. **Timestamps are broker time.** The same convention as `q_14_non_zone.py`
   is used (no EET/EEST -> UTC conversion). If broker is on UTC+2/3, London
   07:00-10:30 UTC actually captures ~05:00-08:30 UTC. This is consistent
   across all historical research but means the "kill zone" label is a
   broker-hour label, not a UTC label.
3. **"Out-of-KZ" bucket uses the kill zone's OR as the reference range**,
   which is arguably the only economically meaningful definition (there is
   no opening event outside a kill zone). Results for this bucket are
   contingent on the London/NY OR still being informative later in the day.
4. **First-close-outside-OR semantics ignore intrabar excursions.** A bar
   that touches OR_high intrabar but closes inside is NOT counted as a
   breakout. This is intentional (closes are the GTOS convention) but
   means 1R-first-touch logic uses intrabar highs/lows while the breakout
   signal itself uses closes — a mild inconsistency flagged here.
5. **OR range is strongly ATR-driven.** If Pearson r(OR_range, ATR14_H1)
   > 0.8, the ORB signal is indistinguishable from "high-volatility session"
   and should be compared against an ATR-matched null rather than treated
   as an independent signal. See ATR table above for the observed r.
6. **No multiple-comparison correction beyond k=2.** We pre-registered two
   primary tests (London, NY). All other tables are descriptive / secondary.
7. **No transaction cost, slippage, or spread model applied.** This is pure
   mid-price analysis.
