# Q-14 Non-Zone Mechanisms

Generated by `research/academic_pipeline/scripts/q_14_non_zone.py` (local, $0 API).

## Hypotheses (pre-registered)

**Q-14.4** — GTOS trades OB retest (fade the cascade).  Prior
belief: fading beats riding, because the edge is stop-cascade mean
reversion (Osler 2000-2005, Cont et al. 2014).  Null: ride-WR equals
actual-WR.  Expected: actual (fade) mean-R > ride mean-R.

**Q-14.10** — No (day, time-bucket) cell shows Wilson-lower-CI > 0.55
and Bonferroni-corrected p < 0.05.  Batch data has only `date (YYYY-MM-DD)` + `kill_zone`; hour-of-day is not recorded.  The
finest achievable bucketing is day-of-week x kill-zone (5 x 2 = 10 cells).

## Data

- Source: `knowledge_base_backtest/analysis/unified_trades_v2_20260331.json` (n=111).
- Historical OHLC: `data/historical_2026/XAUUSD_M15.csv` (2026-01-02 .. 2026-04-10, 6420 bars).
- Overlap window for Q-14.4: 29 trades (25 LONG, 4 SHORT).

## Method

**Q-14.4**:  For each batch trade inside the historical window, build a naive
'ride-the-impulse' counterfactual on M15.  Impulse candle = largest body-range
candle inside the kill-zone hours on the trade's date (proxy for the BOS candle —
true BOS timestamp is NOT recorded in the batch JSON).  Entry = impulse close.
SL = prior 6-bar swing low/high.  TP = entry +/- (sl_dist * planned_rr).  Walk
forward up to `hold_time_candles` M15 bars; first touch wins.  Mark-to-market if
neither touched.  Compare actual_R (fade) vs ride_R (ride) per trade.

**Q-14.10**:  Pivot `day_of_week` x `kill_zone` from batch.  Wilson 95% CI per
cell.  Exact two-sided binomial test against p0=0.55 (the baseline WR a cell
must beat to be 'anomalously strong').  Bonferroni correction: p_bonf = p_raw * 10.
Flag cells with n >= 10, Wilson-lower > 0.55, and p_bonf < 0.05.

## Caveats

1. **Q-14.4 impulse candle is a proxy** — batch JSON has no M15 BOS timestamp.
   Largest-range kill-zone candle is an approximation; results are suggestive,
   NOT production-faithful.
2. **Q-14.4 sample is small** — only 29 batch trades overlap the 2026 historical
   window.  Underpowered for anything stronger than effect-size reporting.
3. **Q-14.10 granularity is coarse** — day x kill-zone (10 cells), not day x hour
   (168 cells).  Hour-of-day analysis requires entry_time recorded in batch JSON
   which does not exist.
4. **Kill-zone timing is already a filter** — cells inside kill zones may appear
   strong simply because the system only trades those hours.  The day x kz
   pivot can only detect 'day-conditional kill-zone' effects, not novel
   intraday signals.
5. **No economic-calendar control** — day x kz cells mix quiet days with NFP
   Fridays, FOMC Wednesdays, etc.  Confounded with macro events.

## Verdicts

- **Q-14.4**: Under the impulse-candle proxy on n=24, FADE beats RIDE by mean-R delta of **+0.553R/trade** (fade WR 70.8% vs ride WR 33.3%).  Paired sign-test p=0.0266.  Prior (fade > ride) is **consistent** with the data.  Proxy-based, low-power — not a substitute for a BOS-timestamped counterfactual.
- **Q-14.10**: **Zero** day-of-week x kill-zone cells survive Bonferroni (p_bonf < 0.05, n >= 10, Wilson_lo > 55%).  Prior (no specific day x time signal beyond kill zones) is **consistent** with the data.  1 cell(s) flagged at the weaker 'informational' threshold (n >= 5, Wilson_lo > 55%) — treat as hypothesis-generating only.
