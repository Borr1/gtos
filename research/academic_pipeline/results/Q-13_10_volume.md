# Q-13.10 Volume Profile (VPOC / LVN) — XAUUSD

Generated by `research/academic_pipeline/scripts/q_13_10_volume_profile.py` (local, $0 API).

## CRITICAL DATA LIMITATION

XAUUSD spot CFD OHLC uses **tick volume** (one unit per broker price update), not **traded volume** (cleared notional on COMEX / LBMA). Tick volume is a known but imperfect proxy for true activity, and is itself biased by price volatility (fast markets print more ticks at the same notional size). **Every finding below is tick-weighted and does not equal true-volume-weighted results.** Any promotion decision based on this analysis must acknowledge this proxy limitation.

## Hypotheses (pre-registered before data inspection)

- **H1**: VPOC reactions show mean absolute 12-candle move (in ATR units) >= 1.2 x mean absolute 12-candle move from random M15 closes in the same eligibility window.
- **H2**: LVN traversal time (median bars to first close outside the LVN bin) <= 50 percent of VPOC dwell time (median bars to first close outside the VPOC bin, from the same kind of first-entry event).

Bonferroni: 2 primary tests, family alpha = 0.05, per-test alpha = 0.025.

Cross-check (not part of the Bonferroni family): if >= 80% of VPOC events co-locate with an H1 or H4 OB zone, any VPOC reaction edge is NOT novel — it just restates the OB edge.

## Data

- `data/historical_2026/XAUUSD_M15.csv` — 6420 bars, 2026-01-02 .. 2026-04-10
- `data/historical_2026/XAUUSD_H1.csv` — 1606 bars (OB context).
- `data/historical_2026/XAUUSD_H4.csv` — 420 bars (OB context).
- Rolling profile eligibility window: M15 idx 1440..6419 (2026-01-23 .. 2026-04-10). First ~30 days are warm-up (no profile).

## Method

- **Volume profile**: 30-day rolling window, $1.00 price bins. For each M15 candle in the window, tick_volume is spread uniformly (TPO-equal) across every $1 bin that the candle's high-low range overlaps.
- **VPOC**: the single bin with highest cumulative TPO-equal volume in the 30-day window at bar i (exclusive of i).
- **LVN**: any bin with cumulative volume > 0 but < 25% of the VPOC volume in the SAME profile. (Empty bins — no prints in the window — are NOT counted as LVN; a never-visited price isn't a 'low-volume node' so much as an untouched area.)
- **Touch / entry event** (first-entry): an M15 close transitions from outside the bin to inside the bin. Dwell = bars (>=1) until the first close back outside the bin. Dwell walk capped at 288 M15 bars (3 days).
- **Reaction**: forward excursion over 12 M15 bars = (max_high - min_low) over bars i+1..i+12, divided by ATR(14) at bar i. This is the symmetric absolute-move metric. Signed close-close move / ATR reported as a diagnostic.
- **Baseline (H1)**: random M15 close events from the same eligibility set (has profile, has ATR, has 12 forward bars). Sampled with replacement at 10x the VPOC event count for variance reduction. RNG seed = 20260417.
- **Inference**: bootstrap (N=10000) for the ratio of means (H1); permutation (N=10000) for the median difference (H2). Both one-sided as stated above.

## Diagnostic — VPOC bin is a SINGLE $1 bin

- M15 closes inside the VPOC bin (any, not first-entry): **13** of 4980 eligible bars (0.26%).
- This rarity is by construction: the VPOC is exactly one $1 bin, and price is rarely at that specific bin. A widened 'VPOC zone' (e.g. VAH/VAL 70% value area) would produce more events but is NOT what the pre-registered hypothesis tests. The small VPOC event count is therefore the honest answer — not a bug.

## H1 — VPOC reactions vs random baseline

- VPOC touch events (first-entry, with forward room): **10**
- Baseline random-level events: **100**

> **Underpowered** (n=10 < 15). Effect size reported; significance not claimed.

| metric | VPOC | Baseline | ratio (VPOC / baseline) |
|---|---|---|---|
| mean abs 12-bar move (ATR) | 5.253 | 4.273 | 1.229 |
| mean signed 12-bar move (ATR) | -0.539 | (n/a) | (diagnostic) |

- Bootstrap 95% CI on ratio: [0.924, 1.585]
- One-sided bootstrap p (P[bootstrap ratio <= 1.0]): **0.0750**
- H1 decision @ alpha=0.025: **FAIL** (need ratio >= 1.2 AND p < 0.025; observed ratio = 1.229, p = 0.0750)

## H2 — LVN traversal vs VPOC dwell

- LVN first-entry events (uncensored): **250** (censored at 288 bars: 0)
- VPOC first-entry events (uncensored): **10** (censored at 288 bars: 0)

> **Underpowered** (lvn_n=250, vpoc_n=10; threshold 15). Effect size reported; significance not claimed.

| metric | LVN | VPOC | ratio (LVN / VPOC) |
|---|---|---|---|
| median bars to exit | 1.0 | 1.0 | 1.000 |
| mean bars to exit | 1.04 | 1.30 | 0.797 |

- Permutation one-sided p (H0: median(LVN)-median(VPOC) == 0; alt: median(LVN) < median(VPOC)): **1.0000**
- H2 decision @ alpha=0.025: **FAIL** (need median ratio <= 0.5 AND p < 0.025; observed ratio = 1.000, p = 1.0000)

## Cross-check — VPOC vs OB co-location

- VPOC events evaluated: **10**
- Co-located with an H1 OB zone: 10 (100.0%)
- Co-located with an H4 OB zone: 10 (100.0%)
- Co-located with H1 OR H4 OB zone: **10 (100.0%)**

**Verdict: co-location >= 80% (100.0%).** Any VPOC reaction edge is NOT novel — it just restates the existing OB zone edge. Do NOT promote VPOC as a separate feature.

## Combined decision

- H1 (VPOC reaction size vs baseline): **FAIL** (obs ratio = 1.229, p = 0.0750)
- H2 (LVN traversal speed vs VPOC dwell): **FAIL** (obs ratio = 1.000, p = 1.0000)
- OB co-location: 100.0% (novelty KILLED)

**VPOC co-locates with existing OBs >= 80%. Even if any test passes statistically, the signal is not novel. KILL this feature — the edge lives in OBs already.**

## Caveats & reproducibility

- Deterministic. RNG seed = 20260417. Bootstrap N = 10000; permutation N = 10000.
- TPO-equal volume distribution is a standard approximation. An alternative HLC-weighted (TPV) distribution might produce different VPOC bins in choppy sessions; not tested here.
- Rolling window is 30 calendar days, not 30 trading days. At the FX/CFD level this includes weekends (no bars), which is acceptable because we filter by bar timestamp, not by calendar-day count.
- Dwell / traversal is censored at 3 days (288 M15 bars). Censored events are EXCLUDED from the median and the permutation test. If the censoring rates differ materially between LVN and VPOC, the comparison is biased; censoring rates are reported above.
- OB detection here uses a simplified 5-bar-fractal swing + last opposite candle backward walk (up to 10 bars). This is a proxy for the production `identify_order_blocks` in `src/components/market_state.py` and is sufficient for a co-location sanity check; it is NOT the production gate.
