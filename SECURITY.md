# Security

Report a vulnerability in private. GitHub private vulnerability reporting is the channel. A public issue, pull request, or discussion is the wrong place for a live credential, an account identifier, a host address, or someone else's data.

This tree is built to contain none of those. If you find one, report it in private and name the file. The coordinator will rebuild the projection from Origin.

The live host pulls only from private Origin `main`, by hand. It does not pull this repository.
