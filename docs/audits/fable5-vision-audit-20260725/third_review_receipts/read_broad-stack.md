## Q5 — Verdict

**BroadV4Policy is the right next Phase-2 move only in its delegation form; full extraction should not start yet; and the shortest honest path to a replay-measured activation candidate does not run through either.**

It does *not* yield Phase-3 throughput — decisions still compute their authority fields — and that should be stated, not finessed.

My Q1 census already falsifies its simplest reading.
4. **Amend G2 for the broad lane:** decision-scoped parity (identity alignment on decision-relevant fields) at Phase 2; byte-level row parity moved to Phase 3's projection gate. As written, G2-exact for BroadV4 secretly imports Phase 3 into Phase 2.
5.
