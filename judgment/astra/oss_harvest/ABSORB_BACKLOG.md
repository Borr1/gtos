## 5. What “A+ sleeves on gate flow” means after this harvest

An A+ sleeve is **not** a Freqtrade strategy file. It is:

1. A **RouteIdentity** (sleeve × symbol × TF) that can assemble `gold_state` with visible missing fields.
2. Features that are **point-in-time honest** (Qlib/Feast rule).
3. Fires that pass **integer envelope** (Challenge-true) and then a **fluid compose** (flow / session / geo / level / cost / event).
4. Costs that are **complete enough to judge** (hftbacktest honesty), else abstain.
5. Labels that **update the learn loop incrementally** (River + our actuator), never a gym place.

That is the absorb. Everything else is scaffolding.
