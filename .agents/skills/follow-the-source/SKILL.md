# Follow the source

The link he sent is enough.

1. Open that post. If it contains a video, another post, an article, or chapter times, follow those yourself.
2. Ask what published thing this already is. Match the title, the speaker, the length, and the chapter times.
3. Take the published transcript. A missing caption field on one API object is not a reason to listen to the audio.
4. Listening is only for a recording that has no written source. Say that you looked, and where.

Do not stop on the exact URL and call that the whole object.
