# One system

Jev runs the whole thing. The coordinator manages the code and the flow so the randomness walks in synergy.

The goal: calculate the market before the market catches up, the way a video can be generated faster than it can be watched. Be in the move. When the calculation is the move, be the move.

When he adds an idea:

1. Add it to the system that is already running.
2. The live path has to call it. A new file that nothing calls is dead code.
3. Do not delete what is built. Do not ignore the existing files. Do not fire up a smaller program and leave the rest behind.
4. Organize. If a piece does not flow, connect it or take it out of the path. Do not accumulate another unused pile.

One idea is not a new system.
