## How To Review A Finished Goal Session

When the owner pastes a closeout:

1. Do not answer from the closeout alone.
2. Pull/read the route directory from disk.
3. Inspect completion audit, decision ledger, verification result, output manifest, and next prompt.
4. Inspect blocker/repair/fail-closed/source-inventory/route-ranking/saturation ledgers where present.
5. Inspect large JSONL distributions when those ledgers drive claims.
6. Compare closeout claims against artifacts.
7. If clean, summarize exact numbers and next route.
8. If not clean, repair or create the exact repair prompt.

For high-value gates, use a reviewer subagent after the orchestrator has read the artifacts, not instead of reading them.

## How To Decide Whether A New G0/G12 Is A Loop

A new G12 is valid when a prior route produced a new artifact needing independent acceptance.

A new G0 is valid when an accepted audit needs synthesis, a gate opening, route prioritization, or evidence-class transition.

It is a loop when it only restates accepted evidence or delays known execution routes.
